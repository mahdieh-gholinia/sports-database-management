# Sports Database 

A MySQL database for managing sports teams, athletes, matches, and tournaments.

## Tables
- Sport, Team, Athlete, Coach, Tournament, Match, Venue, Referee, Award

## Features
- 12+ tables with foreign keys
- Sample data included
- 11 SQL queries (SELECT, JOIN, GROUP BY, UPDATE, DELETE)

## How to Run
```sql
mysql -u root -p < sports_database.sql
```
